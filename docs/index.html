Features

Everything in one window.

No browser tabs, no context switching. Terminal, editor, AI, and dev tools — unified.

Terminal

xterm.js with WebGL rendering. Multi-tab, split panes, and shell integration for bash, zsh, PowerShell, and cmd.

Code Editor

CodeMirror 6 with 44 languages, find & replace, Vim mode, and 9 color themes.

AI Agent

Reads, writes, and runs code with an edit-diff approval flow, auto-approve modes, context summarization, and local voice dictation.

MCP Support

Connect external tool servers via the Model Context Protocol. Browse and install from the official registry.

Image & Video Gen

Generate images (GPT Image 2, Nano Banana 2, Grok Imagine, ComfyUI) and videos (Kling 3.0, Veo 3.1, Seedance 2.0) from chat, with inline preview.

File Explorer

Catppuccin icon theme, fuzzy search, inline rename, multi-select batch actions, drag-to-terminal, and image & PDF preview.

Web Preview

A built-in browser for local dev servers — live-reload previews right next to your terminal, no alt-tabbing.

API Tester

A REST client with method selector, headers, body editor, and JSON pretty-print — test endpoints without leaving the terminal.

Git Integration

Stage, commit, push, and review diffs from the sidebar — with optional GPG signing for GitHub's Verified badge.
