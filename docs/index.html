Scope

01 / 05

Everything in one window

No browser tabs, no context switching. Terminal, editor, AI, and dev tools — unified.

ComponentCovers
terminalxterm.js with WebGL rendering. Multi-tab, split panes, and shell integration for bash, zsh, PowerShell, and cmd.
editorCodeMirror 6. 44 languages, find & replace, Vim mode, and 9 color themes.
ai agentReads, writes, and runs code. Edit-diff approval flow, auto-approve modes, automatic context recovery, long-term reminders, voice dictation, and spoken replies.
multi-projectSeveral projects, one window. A left rail of projects, each with its own tabs, tree, chats, and sessions — all alive in the background, one click to switch.
group chatsAgents that talk to each other. Cross-project group chats: put agents from different projects in one conversation and have them coordinate, review, and split work. Built-in and custom personas join with full tool parity.
mail & socialGmail + X, read-only. Let the agent check your inbox or scan X for reactions and sentiment. It cannot send mail or post, like, or follow — credentials stay in your OS keychain.
assistantTelegram bridge. Chat with your agent from your phone — text, voice notes, photos, and generated media, owner-locked to you. Monitor projects with /tell and approve agent actions with inline buttons.
mcpExternal tool servers via the Model Context Protocol. Browse and install from the official registry.
media genImage & video generation. GPT Image 2, Nano Banana 2, Grok Imagine, and Veo 3.1 — from chat, with inline preview. Kling, Seedance & more via their official MCP servers.
explorerFile tree. Catppuccin icon theme, fuzzy search, inline rename, multi-select batch actions, drag-to-terminal, image & PDF preview.
previewWeb preview. A built-in browser for local dev servers — live-reload previews right next to your terminal, no alt-tabbing.
api testerREST client. Method selector, headers, body editor, and JSON pretty-print — test endpoints without leaving the terminal.
gitStage, commit, push, review diffs from the sidebar — with optional GPG signing for GitHub's Verified badge.
trayCloses to the tray. Agents, watches, and the assistant keep running with the window closed; quiet OS notifications surface approvals and finished runs, and Quit from the tray is the only true exit.

Works with every provider.

Bring your own key. Cloud APIs, local models, or your own endpoint. No lock-in.

Also on board. Image generation (GPT Image 2, Nano Banana 2, Grok Imagine) and video generation (Veo 3.1) — Kling, Seedance, and more are one MCP install away. Plus restart-safe long-term reminders, spoken replies (local Piper, OpenAI TTS, or AssemblyAI), and read-only Gmail & X tools.
